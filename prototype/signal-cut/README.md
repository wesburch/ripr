# RIPR / Signal Cut

Open `index.html` directly in a browser. This is a separate second design concept; it does not replace the root design notes or first prototype.

The brief opening condenses a waveform into the RIPR wordmark. Choose **try a sample rip** to run the 12-second simulation, or use the example source, change the format, and select **rip audio**. The folder control opens inline. **Doctor** contains illustrative diagnostics; **boot** replays the opening.

All audio, waveforms, progress, metadata and recent items are simulated. No source is fetched, dependency checked, folder accessed, or file created.

Keyboard: Tab to move, Ctrl/Command+Enter to rip, Escape to cancel. Outside fields: 1–5 changes format, N starts fresh, O edits the folder, D toggles Doctor. Reduced motion skips the opening and cut effect.

Validation: JavaScript syntax check; desktop and 375px visual inspection; input error, completed rip, history update, keyboard start/cancel, folder Escape rollback, and Doctor focus restoration checked in the browser. Independent review fixes were applied and re-reviewed.
